Reset root password on legacy Sun hardware with a SP (Service Processor)

For servers with ILOM management telnet to your server's SP and type break -y to send it to OK prompt. Then to access the OBP (Open Boot Prompt) type console -y. Now you are ready to boot the host from the net. Type boot net -s and wait about 5 or so minutes before you get dropped to the shell prompt in single user mode. Mount the root partition of the boot disk remove the DES from root’s shadow entry. Then sync twice and then umount the boot partition and reboot the box.

You now can use console access to T2000 as root with no password. Please make sure to give your root a new password
